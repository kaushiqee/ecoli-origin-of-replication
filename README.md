# Computational Identification of the Origin of Replication in E. coli Using Cumulative GC Skew Analysis

## Project Overview

This project aims to identify the approximate origin of replication (OriC) in the *Escherichia coli* chromosome using cumulative GC skew analysis.

Bioinformatics combines biology, computer science, and mathematics to analyse biological data.

## Objectives

- Understand the structure of bacterial DNA.
- Study DNA replication in E. coli.
- Understand GC skew and its biological significance.
- Calculate cumulative GC skew.
- Identify the predicted origin of replication.
- Compare computational predictions with known biological information.

## Methodology

1. Obtain the E. coli genome sequence.
2. Analyse the distribution of guanine (G) and cytosine (C).
3. Assign +1 to G, -1 to C, and 0 to A and T.
4. Calculate cumulative GC skew.
5. Plot the results and identify the global minimum.
6. Compare the predicted position with the known OriC location.
